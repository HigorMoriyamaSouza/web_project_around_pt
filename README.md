# Around the U.S.

Responsive social-style web application built with Vanilla JavaScript and integrated with an external REST API.

## Overview

Around the U.S. is an interactive frontend application in which users can manage profile information and interact with image cards.

The project was developed without a frontend framework, emphasizing JavaScript fundamentals, object-oriented organization, API integration, validation, and responsive interface development.

## Live Application

[Open the live application](https://higormoriyamasouza.github.io/web_project_around_pt/src/)

## Main Features

- Load user profile information from an external API
- Load image cards dynamically
- Edit profile information
- Update the profile avatar
- Create new image cards
- Preview images in a modal
- Like and unlike cards
- Delete cards created by the current user
- Validate forms on the client side
- Display loading feedback during asynchronous operations
- Adapt the interface to different screen sizes

## Technologies

- JavaScript ES6+
- HTML5
- CSS3
- REST API
- Object-Oriented Programming
- BEM methodology
- Responsive Web Design

## Technical Highlights

### External API Integration

The application retrieves and updates profile and card data through an external REST API.

### Object-Oriented Structure

Reusable ES6 classes separate responsibilities and make the application easier to understand, maintain, and extend.

### Dynamic User Interface

The interface updates after user actions without requiring a full page reload.

### Form Validation

Client-side validation helps prevent invalid data from being submitted.

### Responsive Design

The layout adapts to different screen sizes.

### CSS Organization

Styles are divided into reusable blocks following the BEM methodology.
